# W&R City Manager

**UA** Помічник для *Workers & Resources: Soviet Republic*: міста, ресурси на 1000 жителів, каталог будівель і карта-планувальник міста (вкладка Planner). Мови: українська / English / Deutsch.
**EN** Helper for *Workers & Resources: Soviet Republic*: cities, resources per 1000 residents, building catalog and a city planner map (Planner tab). Languages: Ukrainian / English / German.
**DE** Hilfsprogramm für *Workers & Resources: Soviet Republic*: Städte, Ressourcen pro 1000 Einwohner, Gebäudekatalog und eine Stadtplaner-Karte (Reiter Planner). Sprachen: Ukrainisch / Englisch / Deutsch.

## Run / Запуск / Start
1. Download the whole folder (**Code → Download ZIP**, the zip from *Releases*, or the Workshop mod) and unpack it. Keep everything together: the `.bat` and `.py` files and the folders `assets`, `help`, `planner`.
2. Double-click **`W&R City Manager.bat`**. On the first start it finds Python (installs it if missing), downloads the required packages (a few minutes, internet required) and unpacks the game icons from `assets/game_assets.zip` once.
3. Starting with the `.bat` also puts a **desktop shortcut** if there is none (it can then be pinned to the taskbar).

UA: Розпакуй усю папку (файли й папки `assets`, `help`, `planner` мають лежати разом), запусти `W&R City Manager.bat`. Перший запуск знайде або встановить Python і завантажить потрібні пакети (потрібен інтернет). Ярлик на робочому столі з'явиться сам (якщо його немає, `.bat` створить його знову).
DE: Den ganzen Ordner entpacken (alle Dateien und die Ordner `assets`, `help`, `planner` müssen zusammen liegen) und `W&R City Manager.bat` starten. Beim ersten Start wird Python gesucht (oder installiert) und die nötigen Pakete werden geladen (Internet nötig). Die Desktop-Verknüpfung wird automatisch angelegt (fehlt sie, legt die `.bat` sie neu an).
